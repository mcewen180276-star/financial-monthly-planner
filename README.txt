PAYDAY PLANNER
Open index.html in Chrome or Edge to use the app. For Android installation, upload all files to a GitHub Pages repository, then open the GitHub Pages URL and choose Install app / Add to Home screen.

Set your payday day in Settings & backup, add bills, and enter your current bank balance. The dashboard automatically totals unpaid bills from today through the day before the next payday. Mark individual occurrences paid. Budget amounts are additional money you want to reserve until payday.

IMPORTANT: All data is local to this browser/device. Use Download backup regularly. Restoring a backup replaces existing data. The app does not access bank accounts.
